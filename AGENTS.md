# Agent contract

- Keep this repository private until the owner explicitly authorizes publication; do not select a public license implicitly.
- Keep consumer assets, private project dependencies, credentials, host paths, raw campaigns and generated binaries outside Git.
- Preserve full workloads, fixed schedules, input/output/work parity and hard refusal rules. Never select quiet reruns or delete inconvenient observations.
- Run standalone contract tests for affected changes. Windows-native and actual Unity behavior require their own execution evidence; portable mocks are not proof.
- Unity Editors and valid licenses are prerequisites, never implicitly installed. Do not change host global settings or stop unrelated processes.
- Keep project adapters and production correctness policies in the consumer repository. Pin exact source and framework revisions.
- Delegate independent review with explicit file ownership; the coordinating agent reviews and commits changes.
